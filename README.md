# MidWest Design System

A clean, accessible Tailwind CSS design system for AI-powered products.

**[View Documentation →](index.html)**

## Features

- Design tokens for color, spacing, typography, shadow, and radius
- 20+ reusable component classes
- AI conversational UI patterns (chat bubbles, citations, input bar)
- Dark sidebar navigation shell
- Two- and three-column responsive layouts
- Full AI dashboard layout pattern
- Developer handover documentation

## Quick Start

```bash
npm install
npm run dev
```

Open `index.html` to browse all components.

## Tech

- Tailwind CSS v3
- Inter + JetBrains Mono fonts
- No JS framework required
- Dark mode ready
